# Employees — UX Description

## User goal

Find a club member and understand their role or contact context.

## Core experience

- A search field filters by name or role as the user types.
- Employee cards expose avatar/initial, name, role, contact detail, and a **View profile** action.
- **Add member** starts the member-invitation or creation flow.

## Expected behavior

- Search handles no-result states and lets the user clear the query.
- Card actions have clear labels and keyboard focus states.
- The add-member flow validates required information and confirms invitation status.

## Navigation

Reached from the global **Employees** navigation item; profiles may link to Organization.
