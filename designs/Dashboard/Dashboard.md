# Dashboard — UX Description

## User goal

Understand the club’s current status and identify the next useful action in one glance.

## Core experience

- Summary cards show active members, posts this week, and drafts.
- The **Team feed** presents recent updates; opening an item takes the user to its related post or activity.
- The **Upcoming** panel surfaces the next training/match events and priority reminders.
- Persistent navigation allows immediate movement to Posts, Employees, Organization, Settings, or Help.

## Expected behavior

- Summary counts and feed entries are clickable where a detail view exists.
- Empty states explain what will appear and provide a relevant action, such as creating the first post.
- New/high-priority activity should be visually distinguishable without relying only on colour.

## Navigation

Primary landing page after successful sign-in.
