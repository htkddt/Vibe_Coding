# Help Center — UX Description

## User goal

Resolve common questions independently and know how to get human support when needed.

## Core experience

- Global help search finds articles by task or keyword.
- Quick guides provide direct entry to creating a post, finding a member, and managing the account.
- Popular articles provide a lightweight self-service path.
- The support panel offers a clear **Contact support** escalation point.

## Expected behavior

- Search results show titles, short summaries, and an unambiguous article destination.
- If there are no results, present alternative wording plus contact support.
- Contact support should preserve page context and attach a concise issue description when possible.

## Navigation

Reached from the global **Help** navigation item and from Assist fallback links.
