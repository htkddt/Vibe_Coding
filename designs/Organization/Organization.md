# Organization — UX Description

## User goal

Understand the team structure and identify who is responsible for a role.

## Core experience

- A visual organization chart communicates reporting or collaboration relationships.
- Member nodes show names, avatars/initials, and role labels.
- Selecting a node should reveal profile information or take the user to the related employee profile.

## Expected behavior

- Chart layout remains readable at different viewport widths and supports zoom/scroll when required.
- Roles are communicated by text, not colour alone.
- Missing manager/team relationships display a deliberate state rather than broken connections.

## Navigation

Reached from **Organization** in global navigation; connected to Employee profiles.
