# Settings — General UX Description

## User goal

Configure core workspace preferences confidently.

## Core experience

- Tabs separate **General**, **Notifications**, and **Security** settings.
- General controls include workspace name, language, time zone, and compact navigation preference.
- Account card displays the active profile and provides profile/settings account actions.
- **Save changes** commits all modified fields.

## Expected behavior

- Save is disabled until a valid change exists, then shows success/failure feedback.
- Time zone and language selections reflect current values and are keyboard accessible.
- Leaving with unsaved changes requires confirmation.

## Navigation

Reached from global **Settings**; tabs lead to Notifications and Security.
