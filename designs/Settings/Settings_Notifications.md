# Settings — Notifications UX Description

## User goal

Control how and when the portal communicates with the user.

## Core experience

- Clear toggles manage assistant notifications and weekly activity summary.
- Short descriptions explain the effect and delivery channel/cadence.
- **Save changes** persists the chosen preferences.

## Expected behavior

- Toggle labels explicitly state the outcome when enabled or disabled.
- Changes remain local until saved, with a visible unsaved-changes indication.
- Failure to save retains the chosen values and offers retry.

## Navigation

Reached from the Notifications tab in Settings.
