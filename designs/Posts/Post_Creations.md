# Create Post — UX Description

## User goal

Create and publish a clear club update without losing work.

## Core experience

- The editor captures title, message body, and media.
- Post settings define visibility and publishing choice.
- Writing tips help the user produce concise, useful content.
- **Save draft** preserves progress; **Publish post** performs final validation and publishes.

## Expected behavior

- Required fields are marked and validated inline.
- Media upload communicates supported types, upload progress, failure, and removal.
- Publishing shows a review/confirmation state; saving a draft gives visible success feedback.
- Leaving with unsaved edits triggers a confirmation.

## Navigation

Started from the Posts list or dashboard; returns to Drafts, Published, or Post details after the chosen action.
