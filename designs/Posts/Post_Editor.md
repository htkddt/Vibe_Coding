# Edit Draft — UX Description

## User goal

Complete an existing draft, adjust settings, and publish confidently.

## Core experience

- Editable title, rich-text content, and media section retain prior draft data.
- Draft settings define visibility and audience.
- Publishing checklist highlights readiness items before release.
- **Save draft** keeps the work in progress; **Review & publish** starts the publication path.

## Expected behavior

- The editor clearly shows unsaved/saved state.
- Validation focuses the first problem field and explains how to resolve it.
- Review & publish summarizes final audience, content, and irreversible effects before confirmation.
- Discarding changes needs an explicit confirmation.

## Navigation

Opened from the Drafts list; returns to Drafts, Published posts, or Post details.
