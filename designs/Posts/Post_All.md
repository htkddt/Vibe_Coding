# Posts — All Posts UX Description

## User goal

Find, monitor, and manage all club posts from a central place.

## Core experience

- Search locates posts by title or keyword.
- Tabs separate **All posts**, **Published**, and **Drafts**.
- Each list item shows title, context, author/date, and status.
- **Create post** starts content creation; the overview side panel shows published/draft totals.

## Expected behavior

- Sorting changes the displayed order without losing the active filter.
- Opening a post takes the user to its detail view; an overflow menu exposes secondary actions.
- Empty tabs offer a direct next action, for example creating a first draft.

## Navigation

Global **Posts** entry; routes to Create post, Post details, Drafts, and Published lists.
