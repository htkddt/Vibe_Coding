# Designs

## Purpose

This directory will store design deliverables for 179FC_MMS, including Figma exports, approved image assets, user-flow references, and handoff material.

## Plan

1. Establish the visual identity, accessibility baseline, and responsive breakpoints.
2. Create flows for sign-in, member directory, member profile, administration, and assistant interactions.
3. Store approved exports in clearly named feature folders, such as `member-directory/` or `administration/`.
4. Keep source Figma links and export metadata with each design handoff.
5. Update frontend implementation references when a design is approved or replaced.

## Asset Conventions

- Use English names and lowercase kebab-case file names.
- Prefer SVG for icons and vectors; use optimized PNG or WebP only when raster imagery is required.
- Do not store credentials, private member data, or unlicensed assets.

## Documentation Rule

Update this README whenever the design workflow, asset conventions, or approved deliverables change. Update the root README when a design decision changes project-wide behavior or operations.
